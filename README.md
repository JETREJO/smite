# Smite

Base de datos de dioses e items de Smite: guardarlos, consultarlos, agregar los nuevos cuando salgan y actualizar sus stats en cada parche.

La meta es una aplicación con backend, frontend y base de datos. Por ahora (primera versión) solo hay archivos JSON, sin código.

## Estructura

- `gods/` — un JSON por dios. Ver `gods/00-Example-God.json` como plantilla.
- `items/` — JSON con la información de los items. Ver `items/00-Example-Item.json` como plantilla.

Los archivos de ejemplo usan valores inventados, no los reales del juego.
